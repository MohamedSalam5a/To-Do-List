 📝 Todo List App

A simple and interactive Todo List web application built using HTML , CSS , Bootstrap , and JavaScript.  
It helps users efficiently manage their daily tasks with features like search, progress tracking, and local storage.

---

 🚀 Features

- ➕ Add new tasks  
- 🗑️ Delete individual tasks  
- 🧹 Clear all tasks  
- 🔍 Search tasks easily
- ✅ Mark tasks as completed  
- 🔄 Toggle task status (check / uncheck)  
- ❌ Remove completed tasks  
- 📊 Progress bar to track completion  
- ✔️ Input validation  
- 💾 Local Storage support (data persists after refresh)  

---

 🛠️ Technologies Used

- HTML5  
- CSS3  
- Bootstrap 5 (for responsive design and UI components)  
- JavaScript (Vanilla JS)

 📂 How to Use

1. Enter a task in the input field  
2. Click **Add** to insert it into the list  
3. Use the search bar to find tasks quickly  
4. Mark tasks as completed when done  
5. Delete tasks or clear all when needed
